# BO1 Delirium para Plutonium T5

Mod de Zombies para BO1 en Plutonium T5 LAN. Recupera el cuerpo articulado, los parámetros de tareas y el controlador de levantamiento de la versión de desarrollo, adaptados al esqueleto visual de BO1.

La primera ejecución lee una ISO propia de GTA IV de Xbox 360 situada junto a BlackOps.exe. Cuando el lanzador confirma que ha preparado la caché del cuerpo, tareas y levantamientos, se puede retirar la ISO. En el menú Mods de la sesión LAN, selecciona BO1 Delirium antes de iniciar Zombies. La caché es local y contiene datos del juego del usuario.
