# BO1 Delirium para Plutonium T5

Mod de Zombies para BO1 en Plutonium T5 LAN. Recupera el cuerpo articulado, los parámetros de tareas y el controlador de levantamiento de la versión de desarrollo, adaptados al esqueleto visual de BO1.

Descomprime el paquete junto a BlackOps.exe y ejecuta Instalar-BO1Delirium.exe una vez, con Plutonium cerrado y una ISO propia de GTA IV base de Xbox 360 en esa carpeta. El instalador prepara la caché local y registra el plugin nativo y la entrada del menú Mods. Después puedes retirar la ISO, abrir Plutonium normalmente, elegir T5 Zombies en modo LAN y seleccionar BO1 Delirium en Mods. No necesitas un CMD para jugar.

El plugin utiliza el cargador de plugins de Plutonium y solo activa este adaptador en T5 Zombies LAN. La simulación permanece desactivada al seleccionar otro mod. La caché contiene recursos del juego del usuario y no debe compartirse.
