BO1 DELIRIUM | 0.3.0 Beta 13 | COMPILAR / BUILD

ESPAÑOL
Código correspondiente al paquete de instalación. No necesitas una IA para
compilarlo. Requiere Windows x64, MSVC con herramientas Win32, CMake, Rust
estable y Python 3.12 con PyInstaller para el preparador.
VERSION.txt es la versión canónica del mod; CMake genera los recursos de versión.
Ejecuta los comandos siguientes desde la raíz del código. Los ejecutables
nativos son Win32; el worker Rust es x64. Se usa la biblioteca C estática.
No mezcles el número del mod con el número de versión del motor upstream.

ENGLISH
Corresponding source for the installation package. No AI is needed to build.
Requires Windows x64, MSVC Win32 tools, CMake, stable Rust and Python 3.12
with PyInstaller for the preparation tool.
VERSION.txt is the canonical mod version; CMake generates version resources.
Run the following commands from the source root. Native executables are
Win32; the Rust worker is x64. The C runtime is linked statically.
The mod version is separate from the upstream engine version.

COMANDOS / COMMANDS (PowerShell)
cmake -S native -B native-build -A Win32
cmake --build native-build --config Release
ctest --test-dir native-build -C Release --output-on-failure
cmake -S capture -B capture-build -A Win32
cmake --build capture-build --config Release
$env:RUSTFLAGS = '-C target-feature=+crt-static'
cargo test --locked --release --workspace
cargo build --locked --release -p bo1-delirium-worker
python -m PyInstaller --onefile --console --name PrepareBO1 tools/prepare_bo1.py

ARCHIVO DE CONTROLES / CONTROL ARCHIVE
python -c "import zipfile; z=zipfile.ZipFile('bo1delirium_controls.iwd','w',zipfile.ZIP_DEFLATED); z.write('scripts/maps/delirium/controls.gsc','maps/delirium/controls.gsc'); z.close()"

INSTALACIÓN Y PRUEBAS / INSTALLATION AND TESTING
ES: El instalador despliega desde cualquier carpeta, detecta Steam, permite
seleccionar la ISO y registra el plugin nativo oficial de Plutonium. Crea
Jugar - Play BO1 (LAN).lnk con el directorio de trabajo de Plutonium.
La selección de idioma se guarda en installation.ini. Los avisos GSC siguen
loc_language del juego. --quiet --language es/en permite pruebas sin diálogos.
No cierres procesos del usuario. Prueba con el BO1 original y Plutonium LAN.
Los fixtures privados de pruebas requieren recursos preparados por su dueño;
no los publiques ni sustituyas una prueba omitida por un resultado aprobado.

EN: Setup deploys from any folder, discovers Steam, accepts an ISO selection
and registers the official Plutonium native plugin. It creates
Jugar - Play BO1 (LAN).lnk with Plutonium's required working directory.
Language is saved in installation.ini. GSC notices follow the game's
loc_language. --quiet --language es/en supports tests without dialogs.
Do not close user processes. Test with original BO1 and Plutonium LAN.
Private regression fixtures require owner-prepared resources; never publish
them or report a skipped resource-dependent check as passed.
