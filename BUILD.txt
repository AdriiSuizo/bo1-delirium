Corresponding source: BO1 Delirium Plutonium 0.3.0 beta 6
Windows x64; MSVC Win32 build tools, CMake, Rust stable, Python 3.12 + PyInstaller.
Native game adapter and bridge:
  cmake -S native -B native-build -A Win32
  cmake --build native-build --config Release
Read-only BO1 resource capture:
  cmake -S capture -B capture-build -A Win32
  cmake --build capture-build --config Release
Physics worker (x64; install the matching Rust MSVC target):
  set RUSTFLAGS=-C target-feature=+crt-static
  cargo build --locked --release -p bo1-delirium-worker
Preparation tool (uses only Python standard library):
  python -m PyInstaller --onefile --console --name PrepareBO1 tools/prepare_bo1.py
Own control script archive (standard ZIP/IWD; no original game scripts):
  python -c "import zipfile; z=zipfile.ZipFile('bo1delirium_controls.iwd','w',zipfile.ZIP_DEFLATED); z.write('scripts/maps/delirium/controls.gsc','maps/delirium/controls.gsc'); z.close()"
Binary layout is described in manifest.json in the installation archive.
Rename bo1-delirium-worker.exe to runtime/delirium_worker.exe.
Copy BO1SteamDelirium.exe to BO1Delirium/BO1PlutoniumDelirium.exe.
Copy winmm.dll to BO1Delirium/runtime/. The launcher stages it temporarily beside the Plutonium bootstrapper.
Copy CaptureBO1.exe, BO1CharacterCapture.dll, and PrepareBO1.exe to tools/.
Copy bo1delirium_controls.iwd to BO1Delirium/scripts/. The launcher installs this own script into its private profile.
Keep the original native BO1 executable, assets and private generated cache out of redistribution.
The launcher calls --prepare-disc with the BO1 directory and private cache path.
The worker reads Fred.xrt, the pedestrian fragment, taskparams.txt, tuning slots
and recovery motion references from the player's supported GTA IV Xbox 360 ISO.
The exporter follows the existing development lsc4-support pipeline.
The original articulation and task parameters drive the development recovery
controller. BO1's skeleton is retargeted to that articulation for rendering.
Runtime base: the BO1-adapted Delirium core from Steam beta 5 (upstream revision 23ea7cfa2a1000d64870d2549834006d21b3e05c).
The disc importer reads the existing 0.6.0 cache and supplies 384 matching legacy tuning slots. Three BO1 compatibility values remain local to the adapter.
Custom character interface and public configuration references: SuperSloppers/large-steal-car-4
revision 0b0aef3a031dd4d23aa0f99d99e82c2d4063bb36.
